# Sandeep Travelling Agency – Website

Sultanpur, Uttar Pradesh की Travel Agency की website।
Train, Flight, Bus, Hotel और Tour Packages की enquiry, WhatsApp/Call के ज़रिए।

## Pages

| File | Page |
|---|---|
| `index.html` | Home |
| `planner.html` | Custom Tour Planner |
| `booking.html` | Ticket Booking Enquiry |

बाकी pages (About, Services, Packages, Contact) अगले steps में जुड़ेंगे।

## Folder structure

```
sandeep-travelling-agency/
├── index.html
├── planner.html
├── booking.html
├── style.css
├── script.js
└── README.md
```

## Website कैसे चलाएँ

`index.html` पर double-click करें। यह browser में खुल जाएगी। (Fonts के लिए internet चाहिए।)

## अपना नंबर कैसे डालें

`script.js` में सबसे ऊपर `SETTINGS` में अपना phone, WhatsApp नंबर (10 अंक, बिना +91) और email डालें।

## Important

- अभी यह website सिर्फ़ **Booking Enquiry** लेती है, असली ticket booking नहीं।
- Package की कीमतें जान-बूझकर नहीं लिखी गई हैं; "Get Latest Price" बटन है।
- **कभी भी** password, API key या `.env` file GitHub पर upload न करें।
